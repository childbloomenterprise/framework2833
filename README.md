# AEON framework research

AEON controller research and evidence, moved here from
[`childbloomenterprise/aeonconsciousness33`](https://github.com/childbloomenterprise/aeonconsciousness33),
which also holds the unrelated LINC-33 website.

All results are simulation-only. Numeric states are internal estimates; nothing
here claims consciousness.
